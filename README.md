# 🏋️ Gym Management System Platform

A **full-stack Gym Management System** built with **React, Laravel, and MySQL**.
This platform helps gym owners efficiently manage gym operations while providing dedicated spaces for **owners, coaches, and members**.

---

# 🚀 Features Overview

The system is divided into **three main roles**, each with its own permissions and dashboard:

* **Owner (Admin)**
* **Coach**
* **Member**

---

# 👑 Owner (Admin) Features

The gym owner has full control over the platform.

### 📋 Member Management

* Add new members
* Update member information
* Delete members
* Track memberships and subscriptions

### 🧑‍🏫 Coach Management

* Manage gym coaches
* Set and track coach salaries

### 💰 Financial Management

* Track gym income and expenses
* View profits and losses
* Financial statistics and summaries

### 📝 Reclamations Management

* View member complaints
* Manage and respond to reclamations

### 📊 Business Status Dashboard

* Real-time gym statistics
* Visual charts and indicators
* Monitor profitability or losses

---

# 🧑‍🏫 Coach Features

Coaches can manage their training activities and members.

* View assigned members
* Manage training schedules
* Track member progress

---

# 💪 Member Features

Members have access to their personal gym information.

* View membership details
* Access training programs
* Submit reclamations or feedback

# 📥 Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/gym-management-system.git
cd gym-management-system
```

### 2️⃣ Use the project branch (not main)

```bash
git checkout brunsh
```

### 3️⃣ Install backend dependencies

```bash
composer install
```

### 4️⃣ Install frontend dependencies

```bash
npm install
```

---

# ▶️ Run the Project

Start the Laravel server:

```bash
php artisan serve
```

Run the frontend:

```bash
npm run dev
```

Open the application in your browser:

```
http://localhost:8000
```
